# ServeNow - Grocery Delivery Website

A modern, responsive website for grocery and food delivery services with location-based store discovery.

## Features

- **Location-based Store Discovery**: Find registered stores near you using geolocation or manual address input
- **Product Categories**: Browse vegetables, cooked food, household items, and groceries
- **Shopping Cart**: Add items to cart with persistent storage using localStorage
- **User Authentication**: Registration and login functionality
- **Checkout Process**: Complete order placement with multiple payment options
- **Order Confirmation**: Receipt-style confirmation page with order details
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Store Management**: Individual store pages with product listings

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with Grid and Flexbox layouts
- **JavaScript (ES6+)**: Interactive functionality and DOM manipulation
- **Local Storage**: Client-side data persistence for cart and user sessions

## Getting Started

1. Clone or download the project files
2. Open `index.html` in your web browser
3. Navigate through the different pages using the menu

## Features Overview

### Homepage (`index.html`)
- Hero section with location discovery
- Product category navigation
- Featured stores display
- Responsive navigation menu

### Store Discovery (`stores.html`)
- Location input or geolocation-based search
- Filter stores by location
- Store ratings and delivery time display

### Product Browsing (`products.html`)
- Category-based product filtering
- Add to cart functionality
- Product images and pricing

### Shopping Cart (`cart.html`)
- View selected items
- Update quantities
- Remove items
- Proceed to checkout

### Checkout Process (`checkout.html`)
- Delivery information form
- Payment method selection (Card/Cash/Digital Wallet)
- Order summary with totals
- Form validation

### Order Confirmation (`order-confirmation.html`)
- Order number generation
- Order details summary
- Delivery information
- Print receipt option
