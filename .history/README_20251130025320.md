# ServeNow - Grocery Delivery Website with MySQL Backend

A modern, full-stack grocery delivery platform with MySQL database, JWT authentication, and comprehensive admin dashboard.

## 🚀 Features

- **Full-Stack Architecture**: Node.js/Express backend with MySQL database
- **JWT Authentication**: Secure user registration, login, and session management
- **Role-Based Access Control**: Customer, Store Owner, and Admin user types
- **Location-based Store Discovery**: Find registered stores near you using geolocation
- **Product Management**: Complete CRUD operations for products, stores, and users
- **Shopping Cart**: Persistent cart with localStorage integration
- **Order Management**: Complete order lifecycle from placement to delivery
- **Admin Dashboard**: Comprehensive management interface for all system entities
- **RESTful API**: Well-documented API endpoints for all operations
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## 🚀 Quick Start

### 1. Clone and Install Dependencies

```bash
git clone <repository-url>
cd ServeNowHtml
npm install
```

### 2. Configure Environment

Update the `.env` file with your MySQL credentials:

```env
DB_HOST=localhost
DB_USER=your_mysql_username
DB_PASSWORD=your_mysql_password
DB_NAME=servenow_db
DB_PORT=3306
JWT_SECRET=your_super_secret_jwt_key_here_change_in_production
```

### 3. Setup Database

```bash
# Initialize the database and create tables
node setup-db.js
```

This will create:
- `servenow_db` database
- All necessary tables
- Sample data including admin user

### 4. Start the Server

```bash
npm start
```

The server will start on `http://localhost:3000`

### 5. Access the Application

- **Website**: http://localhost:3000
- **Admin Dashboard**: Login with admin credentials and access admin.html

## 📚 API Documentation

### Authentication Endpoints

- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `GET /api/auth/profile` - Get current user profile

### Store Endpoints

- `GET /api/stores` - Get all stores
- `GET /api/stores/:id` - Get store by ID
- `POST /api/stores` - Create new store (Store Owner/Admin)
- `PUT /api/stores/:id` - Update store (Store Owner/Admin)
- `DELETE /api/stores/:id` - Deactivate store (Admin)

### Product Endpoints

- `GET /api/products` - Get all products (with optional category/store filter)
- `GET /api/products/:id` - Get product by ID
- `POST /api/products` - Create new product (Store Owner/Admin)
- `PUT /api/products/:id` - Update product (Store Owner/Admin)
- `DELETE /api/products/:id` - Deactivate product (Store Owner/Admin)

### Order Endpoints

- `GET /api/orders/my-orders` - Get user's orders
- `POST /api/orders` - Create new order
- `GET /api/orders` - Get all orders (Admin)
- `PUT /api/orders/:id/status` - Update order status (Store Owner/Admin)

### User Management (Admin Only)

- `GET /api/users` - Get all users
- `PUT /api/users/:id` - Update user

### Categories

- `GET /api/categories` - Get all categories
- `POST /api/categories` - Create category (Admin)
- `PUT /api/categories/:id` - Update category (Admin)

## 🎯 User Roles & Permissions

### Customer
- Browse stores and products
- Add items to cart
- Place orders
- View order history

### Store Owner
- All customer permissions
- Create/manage their own stores
- Add/edit/delete products in their stores
- Update order status for their stores

### Admin
- All permissions
- Manage all users (change roles, activate/deactivate)
- Manage all stores and products
- Access to all orders and analytics
- Create/manage categories

## 🐛 Troubleshooting

### Common Issues

1. **Database Connection Failed**
   - Verify MySQL server is running
   - Check credentials in `.env` file
   - Ensure database user has proper permissions

2. **Port Already in Use**
   - Change PORT in `.env` file
   - Kill process using the port

3. **CORS Issues**
   - Ensure frontend and backend are on the same domain or CORS is properly configured
