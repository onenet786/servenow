ACTIVE SCREEN PURPOSE
Dashboard Overview: Serves as the high-level operations mission control of servenow.pk. Tracks Today's and All-time order totals, delivered counts, pending kitchen preparation, and real-time activity feed.
WHY ESSENTIAL & FAILURE RISK
Without this dashboard, platform supervisors cannot detect order bottlenecks (e.g. pending orders piling up in Lahore kitchens) or track cancelled orders, leading to massive customer churn.
BACKEND API & SQL PIPELINE
GET /api/admin/dashboard-stats
// routes/admin.js SELECT COUNT(*) AS today_orders, SUM(status = 'delivered') AS today_delivered, SUM(status = 'pending') AS today_pending, SUM(status = 'cancelled') AS today_cancelled FROM orders WHERE DATE(created_at) = CURDATE();
OPERATIONAL USER DECISION
Operations managers review order volume velocity and inspect recent stores like "Halwa Puri By Faisalabad Bakery" to ensure merchant onboarding compliance.
